# Demographic Data Analyzer

Proyecto de análisis de datos usando Python y Pandas.

## Tecnologías
- Python
- Pandas
- Google Colab

## Objetivo
Analizar datos demográficos del censo 1994 utilizando DataFrames.

## Funciones realizadas
- Conteo por raza
- Promedio de edad
- Análisis de salarios
- Estadísticas por educación
